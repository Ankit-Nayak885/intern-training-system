# Intern Training & Performance Management System

A browser-based application built with core JavaScript to manage interns,
attendance, assessments, tasks and overall performance.

## Features
- Dashboard with key statistics
- Intern management (add, edit, delete, search, filter)
- Daily attendance tracking
- Assessment records with score validation
- Task assignment with status and overdue detection
- Performance ranking: attendance 20%, assessments 40%, tasks 40%
- Data saved in the browser using localStorage
- CSV export of the performance report

## Technologies
HTML, CSS, JavaScript (no frameworks)

## How to run
Open `index.html` in any modern browser.
